## 项目简介

拼图中国是一个功能强大的中国地图可视化平台，提供：

-  **3D 地图渲染**：基于 MapLibre GL 的高性能 3D 地图展示
-  **数据分析**：支持 Excel/CSV 数据导入，自动生成颜色映射
-  **颜色定制**：灵活的板块颜色管理，支持自定义配色方案
-  **绘图工具**：丰富的绘图功能（线条、箭头、椭圆），支持旋转和缩放
-  **多级地图**：支持省级、市级、区级三级行政区划切换
-  **交互操作**：直观的鼠标操作，支持板块选择、聚焦、重置等功能

##  功能特性

###  地图功能

- **3D 立体展示**：支持俯仰角和旋转，提供沉浸式地图体验
- **多级切换**：省级 → 市级 → 区级，无缝切换不同行政级别
- **板块交互**：
  - 左键点击：选择/取消选择板块
  - 右键点击：打开颜色定制面板
  - 聚焦已选区域：自动缩放至选中区域
  - 重置所有板块：恢复默认状态

###  数据分析

- **数据导入**：支持 `.xlsx`、`.xls`、`.csv` 格式文件
- **格式验证**：智能检测地名列，确保数据格式正确
- **颜色映射**：多种预设配色方案（Blue-Sky、Sunset-Orange、Viridis-Eco 等）
- **数值映射**：根据数据值自动计算高度和颜色
- **模糊匹配**：支持地名模糊匹配，提高数据匹配准确率

###  绘图工具

- **线条工具**：绘制直线，支持自定义颜色、粗细、厚度
- **箭头工具**：
  - 直线箭头和曲线箭头
  - 可调节箭头头部大小和高度
  - 支持透明度渐变效果
  - 自定义箭头宽度（尾部宽度、中间宽度）
- **椭圆工具**：
  - 支持圆形和椭圆
  - 可调节长轴和短轴
  - 支持旋转和空心效果
  - 自定义厚度和颜色

###  颜色管理

- **自定义颜色**：为每个板块单独设置颜色
- **预设方案**：多种专业配色方案
- **数据驱动**：根据导入的数据自动生成颜色映射

###  背景样式

- **底图模式**：OSM 底图
- **单色模式**：纯色背景

##  快速开始

### 在线使用

直接访问 [在线演示](https://van-wu1.github.io/ChinaPuzzleVis/) 即可使用，无需安装。

### 本地部署

1. **克隆项目**
   ```bash
   git clone https://github.com/van-wu1/ChinaPuzzleVis.git
   cd ChinaPuzzleVis
   ```

2. **启动本地服务器**

   使用 Python：
   ```bash
   python -m http.server 8000
   ```

   或使用 Node.js：
   ```bash
   npx http-server -p 8000
   ```

3. **访问应用**

   打开浏览器访问 `http://localhost:8000`

##  技术栈

- **MapLibre GL JS**：3D 地图渲染引擎
- **Turf.js**：地理空间计算库
- **SheetJS (XLSX)**：Excel 文件解析

- **HTML5 / CSS3**：用户界面

##  使用指南

### 数据导入

1. 点击 **"导入 Excel 数据分析"** 按钮
2. 选择包含地名列的 Excel 或 CSV 文件
3. 文件要求：
   - 必须包含一列地名（列名包含：名称、地区、城市、省份等关键词）
   - 地名列数据主要为中文字符（2-20 个字符）
   - 至少包含一行数据

4. 导入成功后：
   - 在 **"属性表"** 标签页查看数据
   - 在 **"符号系统"** 标签页选择分析指标和配色方案

### 绘图工具

1. 切换到 **"工具模式"**
2. 选择绘图工具（线条/箭头/椭圆）
3. 在地图上点击并拖拽绘制
4. 使用控制点调整图形大小和位置
5. 使用旋转控制点调整角度
6. 在右侧属性面板调整颜色、大小等属性

### 板块定制

1. **选择板块**：左键点击地图上的板块
2. **修改颜色**：右键点击板块，在弹出面板中选择颜色
3. **聚焦区域**：选择板块后，点击 **"聚焦已选区域"** 按钮
4. **重置**：点击 **"重置所有板块"** 恢复默认状态

## 🎯 功能演示

### 数据可视化

导入包含地区数据的 Excel 文件，系统会自动：
- 识别地名列
- 根据数值计算高度和颜色
- 生成 3D 可视化效果

### 多级地图切换

- 点击地图上的板块可以进入下一级（省 → 市 → 区）
- 使用历史记录返回上一级
- 支持快速切换不同行政级别

### 自定义绘图

- 绘制箭头标注重要路径
- 绘制椭圆标记重点区域
- 所有图形支持旋转、缩放和自定义样式

##  注意事项

1. **数据格式**：导入的 Excel/CSV 文件必须包含有效的地名列
2. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Edge、Safari）
3. **性能优化**：大数据量时建议使用模糊匹配功能提高性能
4. **地图数据**：地图数据存储在 `shp/` 目录下，支持本地和在线加载
